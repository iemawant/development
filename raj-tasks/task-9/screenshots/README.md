# اسکرین‌شات‌های پایلوت رایکا

این پوشه برای تصاویر واقعی پیش‌نمایش موبایل و تأیید آرشیا است.

در حال حاضر تصویر واقعی در این پوشه ثبت نشده است. پس از دریافت ورودی‌های معتبر و ساخت پیش‌نمایش:
1. تصویر از دستگاه/viewport واقعی تهیه شود.
2. تاریخ، اندازه viewport، URL صفحه و سناریوی تست ثبت شود.
3. مسیر QR تا منوی واقعی و هر دو CTA در تصویر/ویدئوی جدا یا مجموعه شواهد قابل بررسی نشان داده شود.
4. تصویر برای تأیید آرشیا در Issue #9 پیوند داده شود.

تصویر نمونه، mockup یا خروجی تولیدشده نباید به‌عنوان شاهد تست واقعی معرفی شود.

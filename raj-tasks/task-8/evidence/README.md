## وضعیت پیش‌نمایش
فایل [preview/index.html](../preview/index.html) یک پیش‌نمایش ساختاری است. تنها لینک فعال آن، آدرس صفحه اصلی رایکا است که کاربر ارائه کرده؛ این لینک از محیط اجرا تست نشده و به‌عنوان لینک منو معرفی نمی‌شود. CTA منو، تماس و درخواست راهکار مشابه عمداً غیرفعال‌اند.
